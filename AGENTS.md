# Соглашения проекта

## Документация (Obsidian)

Документация проекта ведётся в Obsidian-хранилище, вне репозитория:

`/Users/andrey/Work/Obsidian/Obsidian/Проекты/Смета Кондитера/`

`Смета Кондитера.md` — индексная заметка (MOC), ссылается на тематические заметки:
архитектура, модель данных, схема БД, serverless API, интерфейс, доменная логика,
стек, переменные окружения, тестирование/CI, структура репозитория, история разработки.

**Правило:** при изменении кода (фичи, схема БД, миграции, env-переменные,
npm-скрипты, структура файлов, API-эндпоинты) — обновлять соответствующие
заметки в этой папке, а также «История разработки.md» (вехи и список свежих
коммитов). Документация пишется на русском, стиль — как в существующих заметках
(frontmatter с `tags: [project/baker-estimate, ...]`, ссылка `> Индекс: [[Смета Кондитера]]`).

## Проверка изменений

- `npm run test:run` — юнит-тесты Vitest (обязательно после правок `src/`)
- `npm run build` — `tsc -b && vite build` (проверка типов + сборка)
- `npm run test:e2e` — Playwright (сам поднимает dev-сервер)
- `npx oxlint` — линтер
